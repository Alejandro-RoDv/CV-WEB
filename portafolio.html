01 / CONTEXTO

Visión general

El laboratorio reproduce, a pequeña escala, una infraestructura de red y sistemas con equipamiento físico y máquinas virtuales. Permite configurar servicios, aplicar políticas de seguridad, comprobar resultados y documentar decisiones técnicas.

MetodologíaDiseño → Despliegue → Pruebas → DocumentaciónProyecto en evolución; se distinguen los servicios operativos de las ampliaciones previstas.
02 / REDES

Arquitectura y segmentación

El router principal gestiona las VLAN y el tráfico entre segmentos. El switch distribuye las conexiones cableadas y la red inalámbrica ofrece acceso diferenciado por finalidad.

Segmentación lógica

Separación de los equipos de administración, servicios, clientes y pruebas. Las comunicaciones entre VLAN se controlan mediante reglas de cortafuegos.

03 / EQUIPAMIENTO

Infraestructura física

Componentes de red y equipos de servicio que forman la base del laboratorio.

ENRUTAMIENTO

Router MikroTik RB5009

Gateway de los segmentos internos, routing, NAT y filtrado entre redes.

CONMUTACIÓN

Switch MikroTik CRS326

Conexiones cableadas, puertos de acceso y transporte de VLAN.

RED INALÁMBRICA

Puntos de acceso

Conectividad Wi-Fi para clientes, pruebas y dispositivos asociados.

CÓMPUTO

Linux, Raspberry Pi y máquinas virtuales

Servidores ligeros y entornos virtualizados para ejecutar servicios y prácticas.
